# Zakładka — reading app (spec shared by all builders)

Owner: Mateusz. No coding background. Reads Polish books only, on paper and on a Kindle via Legimi. Has a Goodreads account. Uses an Android phone.
**The whole UI is in Polish** (natural Polish, correct diacritics, proper plural forms: 1 książka / 2 książki / 5 książek, 1 strona / 2 strony / 5 stron, 1 minuta / 2 minuty / 5 minut). Dates use pl-PL.

## Stack (same pattern as the owner's Tempo app at C:\Users\mateu\Documents\tempo-app; read it for conventions)
- Static PWA in `docs/` (served later from GitHub Pages at https://matjan00.github.io/zakladka/). Vanilla JS ES modules, no build step, no npm deps at runtime. CDN libs allowed only from cdn.jsdelivr.net with exact versions (e.g. tesseract.js).
- Phone-only, local-first. No accounts. Data in **IndexedDB** (db `zakladka`) through `docs/js/store.js` (one place). Photos (covers the user shoots, page photos) also in IndexedDB as Blobs. Call `navigator.storage.persist()`. Backup export/import (JSON incl. photos as base64) in Settings.
- `docs/sw.js` offline cache: `const VERSION = 'zakladka-v1'` and a `// FILES-START ... // FILES-END` block (see tempo-app/docs/sw.js). `docs/js/version.js` exports `APP_VERSION = '0.1.0'`. `node scripts/release.cjs` bumps both. Install with `cache:'reload'`. Show an "Aktualizacja dostępna" banner when a new SW is waiting.
- Local preview: launch config `zakladka` → http://localhost:5210 (`scripts/serve.cjs`). Preview browser can't register the SW on localhost; that's not an app bug.
- `docs/manifest.webmanifest`, icons in `docs/icons` (generate PNGs 192/512 + maskable via a node script without deps, like tempo-app/scripts/make-icons.cjs, or an SVG→PNG approach that works offline).

## External data
- **Biblioteka Narodowa API** (complete Polish metadata, no CORS → via proxy): `https://data.bn.org.pl/api/institutions/bibs.json?title=...&author=...&isbnIssn=...&limit=20`. Fields: title, author, isbnIssn, genre, subject, domain, kind ('książka'), publicationYear, language, marc.fields (field '300' subfield 'a' like "391, [9] stron :" → page count). Skip kind ≠ książka and audiobooks ("1 CD"). Clean titles: cut at " / ", strip trailing " :", authors like "Reymont, Władysław Stanisław (1867-1925)" → "Władysław Stanisław Reymont" (first person only; later names are translators/illustrators).
- **Open Library** (CORS OK, call directly): search `https://openlibrary.org/search.json?q=...&fields=title,author_name,isbn,cover_i,number_of_pages_median,first_publish_year,subject&limit=10`; covers `https://covers.openlibrary.org/b/isbn/{isbn}-M.jpg?default=false` or `/b/id/{cover_i}-M.jpg`. Polish coverage is partial → use for covers + fallback.
- Google Books keyless is blocked (quota 0) — don't use.
- When no cover exists, render a **generated typographic cover** (title + author on a colour derived from a hash of the title, cloth/linen feel). It must look intentional and beautiful, not like a placeholder. The user can also photograph a cover.
- **Proxy**: Supabase edge function `books-proxy` in `supabase/functions/books-proxy/index.ts` (Deno), deployed later into the owner's existing Supabase project ref `txhcnqwrdazgaxjwabln` (URL https://txhcnqwrdazgaxjwabln.supabase.co/functions/v1/books-proxy), `--no-verify-jwt`. GET only, allow-list of upstream hosts: `data.bn.org.pl`, `www.nekla-bpmig.sowa.pl`. Params: `?bn=<query string>` or `?sowa=<search phrase>`. For sowa it parses the HTML server-side and returns JSON. CORS for https://matjan00.github.io and http://localhost:5210. Short timeouts, strict input length limits, cache headers (BN 1 day, sowa 1 h). Config in `docs/js/config.js` (`PROXY_URL`). Until the proxy is deployed the app must degrade gracefully: Open Library search still works, manual add always works, library check shows "Sprawdź w katalogu" as a link to the catalogue search page.
- **Biblioteka Publiczna Miasta i Gminy Nekla** catalogue (SOWA OPAC): search URL `https://www.nekla-bpmig.sowa.pl/index.php?KatID=0&typ=repl&plnk=q__<words joined by +>&sort=byscore&view=1`. Each result carries `data-title="..."`, `data-author`, record links `index.php?KatID=0&typ=record&001=...`, and `<span class="av-status-available" title="Są egzemplarze dostępne do wypożyczenia">` (other av-status-* classes = not available / on loan). The library also offers free Legimi codes (https://www.legimi.pl/biblioteka_nekla/) → mention in the library screen.

## Features
1. **Biblioteczka (library)**: shelves Czytam / Chcę przeczytać / Przeczytane / Porzucone (+ custom tags). Add a book by searching (BN + OL merged, dedupe by ISBN), by scanning a barcode (`BarcodeDetector` with EAN-13, camera via getUserMedia; fallback typing the ISBN), or manually. Format: papier / Kindle (Legimi) / audiobook. Book detail: cover, author, pages, genre, year, ISBN, dates started/finished (several reads allowed), rating 0.5–5 stars, review, notes, tags, current page / progress.
2. **Statystyki**: books & pages per month/year, yearly goal with pace ("3 książki przed planem"), favourite genres/authors, average length, average days per book, reading speed (pages/hour from sessions), streak of reading days, year in review. Charts in hand-written SVG (no chart libs), matching the design.
3. **Sesje czytania (timer)**: start/pause/stop for the current book; timestamp-based (survives reload); at the end ask for the page reached; computes pages/hour; estimate "skończysz za ~3 h 20 min / około czwartku" from the speed and recent pace. Manual add of a past session. Sessions update the book's progress.
4. **Cytaty (quote vault)**: save quotes per book with page, tags, an optional note; add by typing, by **photographing a page with OCR** (tesseract.js from jsdelivr, Polish `pol` traineddata, lazy-loaded only when used, crop/select text before saving), or by **importing Kindle `My Clippings.txt`** (Legimi books on a Kindle write highlights there; parse Polish and English Kindle formats; dedupe; match to library books by title/author, fuzzy). Search and filter; "cytat dnia" (quote of the day) on Home; share a quote as a nice image card (canvas → share/download).
5. **Co dalej? (what next)**: rule-based picker from Chcę przeczytać by mood/length/genre/format/"available in the Nekla library now"; "Zaskocz mnie" random; suggestions of other books by authors/genres the owner rated ≥4 (via BN search by author), clearly marked as suggestions to add.
6. **Biblioteka w Nekli**: check availability of want-to-read books (per book button + "sprawdź wszystkie" with a gentle rate limit); show Dostępna / Wypożyczona / Brak w katalogu, last checked time, link to the record in the catalogue. Cache results in IndexedDB.
7. **Import z Goodreads**: the owner exports `goodreads_library_export.csv` (Goodreads → My Books → Import and export → Export library). Parse it (quoted CSV, ISBN like `="978..."`), map exclusive shelves read/currently-reading/to-read → Przeczytane/Czytam/Chcę przeczytać, ratings, Date Read, Date Added, pages, review, other shelves → tags. Preview before import, dedupe, then fetch covers in the background. Explain in Polish with click-by-click steps how to export from Goodreads.

## Design direction (the owner asked for a very well-designed app with a book motif)
Use the `impeccable` skill. Theme: a warm, literary object, like a well-made book or an old library card catalogue rather than a generic app. Ideas to develop (not all mandatory): paper-cream background with subtle grain, ink-black and a deep bookcloth accent colour, a serif for reading text (e.g. Literata / Fraunces / Newsreader from Google Fonts; must support Polish diacritics) + a clean sans for UI; book spines on a shelf view; ribbon-bookmark for active tab/progress; ex-libris stamp for finished books; library-card style for loans; drop caps / fleurons as small details. A real dark mode ("czytanie nocą") that is not just inverted. Mobile-first (360–430 px), large tap targets, bottom navigation with 5 tabs: Start, Półka, Sesja, Cytaty, Statystyki (Co dalej / Biblioteka / Ustawienia reachable from Start/Półka). Smooth but restrained motion; respects prefers-reduced-motion. Fonts must also load offline after first visit (cache them in the SW or self-host).

## Ownership / module contract
`docs/js/app.js` (shell, router, bottom nav, sheets), `store.js` (IndexedDB), `ui.js` (shared components: sheet, toast, star rating, cover, empty states, plural helper `pl(n, 'książka','książki','książek')`), `books.js` (library, add, detail), `sources.js` (BN/OL/proxy lookup), `config.js`. Feature modules each export `render(container, ctx)` and register a route. Each builder owns their own files; changes to shared files only in small, clearly needed additions. Keep `docs/css/` split by feature on top of `base.css` (tokens).

## Quality bar
Test in the preview browser (prefer page text / read_page over screenshots; a few screenshots for design checks are fine). No console errors. Works offline after first load. Everything must survive reload. Empty states written warmly in Polish. Never lose user data (backup/restore tested).
